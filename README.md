# Anime Gachapon

A fun, interactive Gachapon-style anime recommendation website that helps you discover new random anime from the top-rated list.

## Features

- Gachapon machine animation with 1 gachapon
- Fully responsive design (mobile/tablet/desktop)
- Direct links to MyAnimeList for more info
- Error handling for failed API requests

## Tech Stack

- Pure HTML5, CSS3, JavaScript (no frameworks)
- Jikan API (unofficial MyAnimeList API)
- Modern CSS with flexbox and animations

## How to use

1. Open index.html in your browser
2. Click the "PULL!" button to spin the gachapon
3. Wait for the animation to complete
4. View the recommended anime in the result section
5. Click the "MyAnimeList" link to learn more about the anime

## Browser Support

- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)
- Mobile browsers

## API Rate Limits

Jikan API has rate limits (3 requests/second). The app loads 25 anime once on page load, so it's well within limits.
